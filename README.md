# AE IPCG — Landing Page

Landing page institucional simples e responsiva para a Associação dos Estudantes do IPCG.

## Estrutura

- `index.html` — conteúdo e estrutura
- `/src`
  |- `/css` — visual e responsividade
  |- `/script` — menu mobile, animações e formulário demonstrativo
  |- `/pages` — incorporação de páginas internas

## Como executar

Abra `index.html` no navegador.

## Pontos a personalizar

- Email e contactos
- Logótipo oficial da AE
- Cores institucionais
- Plano de actividades / prioridades
- Links das redes sociais
- Formulário de contacto (ligar a backend ou serviço de email)
